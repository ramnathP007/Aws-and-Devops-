Load Balancer:
==============
    -> For example We have a t2.Large EC2 machine which can Handle 10K user request, but at the peak time we are receiving around 15K user request
    -> So for this we may add more number of EC2 instances for this and we need to distribute the 15K load into these instances and for this we use Load Balancer
    -> There are types of Load Balancer
        - Classic (Outdated)
            # Supports the HTTPS,HTTP and TCP Protocol (We can say it works on L7 and L3 layer)
        - Application
            # Supports the HTTP and HTTPS Protocol (We can say it works only on L7 layer)
        - Network
            # Supports the TCP and UDP Protocol (We can say it works only on L3 layer)
        - Gateway
            # Used for Third party Applications 
            # Used for firewall, security compliance Application load Balancing
        
HTTP Vs HTTPS:
==============
    -> HTTP
        - HTTP transmits the data in the plain text
        - This will not use the SSL Certificate 

    -> HTTPS
        - HTTPS transmits the data as a encrypted text
        - This will use the SSL Certificate


TCP Vs UDP:
===========
    -> TCP
        - Transmission Control Protocol has a 3 way handshake SYN-SYNACK-ACK and this will establish a connection for the file Transmission
        - This is reliable
        - Used for a file Transmission as we need to send without any lack of data 
    -> UDP
        - User Datagram Protocol has no 3 way handshake and this is used where the Transmission is not to be acknowledged
        - This is non reliable
        - Used in Streams and Video Games in browsers as this need not have to be 100% transmited and this may have a lack or data loss


Classic LB:
===========

        - Give the name for the load Balancer name as sy Classic-LB
        - Scheme we can select Internet-facing if the LB need to communicate with the Internet and internal if the LB is for internal services
        - In the Network mapping we can select the VPC and the Availablity zones for the LB where the EC2 is created
        - We can select the SG or create a SG for the LB
        - Now we should select the listeners and routing 
            # listener Protocol and listener Port is where the  Port listened by the LB
                > HTTP:80
            # Instance Protocol and Instance Port is where the Port Listened by the instances
                > HTTP:80
        - Now we should set the Health check
            # Traffic is only routed to the Healthly instances
            # We can configure the Health check
                > Ping Protocol: HTTP
                > Ping Port: 80
                > Ping Path: /index.html
        - In the instances tab select the instances where the same Application is running
        - We can select the attributes
            # We can enable the cross-zone load Balancing
            # We can enable connection draining (The maximum time for the load Balancer to allow the existing connection to complete, when the max time is reached the LB will forcibly close the existing connection)
                > Timeout (draining interval)

        - Review the summary and click create load Balancer 
    -> We can set the Algorithm based on our requirement (RR,Weighted RR, IP hash,LC,Secure Sticky etc..)

ALB LB:
===========
    -> Path Based routing 
        - If a LB url is going to two serve different Application we can use that specific path in the url so that the request will be routed to that EC2 instances
            # http://abc.com/green this will go to the app group which has the green Application
            # http://abc.com/red this will go to the app group which has the red Application
    -> Host Based routing
        - If we need to route to the specific host we can use the Host based routing
            # http://green.abc.com
            # http://red.abc.com
    -> Sticky session is used to set a time limit to maintain the session for the (If there is inactivity for the mentioned time the session will be terminated)
    -> We can create the ALB using the following steps
        - We need to create a Target group or App group to assign more same Application server for the high Availablity
        - We can create the Target group by the following steps

            # In the Basic configuration choose the Target type as instances
            # Give a Target group name as GreenTG
            # Choose the Protocol:Port which the LB is listening 
                > HTTP:80
            #Choose the IP Address type as per the requirement
                > IPv4 (select)

            # We can add the tag if we want

Auto Scaling Groups:
====================
    -> To automatically increase or decrease the instances based on the Traffic
    -> Increasing the number of instances based on the traffic is called Horizontal Scaling
    -> Increasing the resources and type of the resource of the instances is called vertical Scaling

        - Click create ASG
        - Give a name to the ASG
        - In the select Template, select the Template you want for the EC2 machine to be created or we can create the Template using the below steps
            # In the Template page click create Template
            # Give a name to the Template
            # Give a template Version description 
            # In the Launch template contents select the Quick start and select the AMI we want 
            # select the instance type now or we can select later in ASG
            # select the key pair
            # select the SG 
            # select the storage volumes
            # Tag is optional
            # we can give the package installation scripts if we want in the User meta data or Create a template which is taken from the existing EC2 machine which has that package
            # Click Launch ASG
        - Give next
        - Now we can also override the template
        - Now select the VPC and AZ and Subnets
        - Give next
        - Now if we want to attach to the existing LB or create a LB for the ASG we can do or without LB we can create the ASG as well
        - Give next
        - In the Group size
            # select the desired size (stable count)
